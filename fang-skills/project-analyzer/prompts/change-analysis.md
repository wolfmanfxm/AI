# Migration Notes Prompt

输出格式参见下方模板说明

## 对比流程

1. 确认 Vault 路径和项目名称
2. 检查上次 5 份知识文件是否存在
3. **首次执行**：全部标记 `[NEW]`，简要说明"基线建立"
4. **非首次**：逐文件对比，逐项标记

## 对比维度

- **架构**：模块增删改、Store 变化、路由调整
- **组件**：新增高复用组件（≥2 引用）、接口变化、废弃组件
- **编码**：新模式出现、旧模式淘汰、命名/import 变化
- **UI**：新模式出现、旧模式替代
- **API**：目录变化、新模块、约定变更

## 标记规则

| 标记 | 触发条件 |
|------|---------|
| 🆕 NEW | 上次无，本次有 |
| 🔄 CHANGED | 上次有，本次不同 |
| ❌ REMOVED | 上次有，本次无 |
| ✅ CONFIRMED | 两次一致 |

输出：先列变化项，再列确认项。确认项可合并（如"✅ 15 组件未变化"）。
