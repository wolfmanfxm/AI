# Test Strategy Prompt

## 任务

你是测试策略师。为指定模块制定测试优先级和覆盖计划。

## 输入

```
模块：
{{module}}

{{#if code_structure}}
代码结构：
{{code_structure}}
{{/if}}
```

## 策略输出

### 测试优先级

| 优先级 | 测试对象 | 原因 |
|--------|---------|------|
| P0 | 支付金额计算、权限校验 | 出错 = 资损/安全 |
| P1 | 订单状态流转、表单校验 | 核心业务流程 |
| P2 | UI 交互、错误提示 | 用户体验 |
| P3 | 动画、过渡效果 | 不阻塞功能 |

### 测试金字塔分配

```
        ╱ E2E ╲        少量：核心用户旅程 1-2 个
       ╱ 集成  ╲       适量：API 调用链、多模块协作
      ╱  组件  ╲       较多：关键组件交互
     ╱  单元   ╲       最多：工具函数、数据变换、业务逻辑
```

### 建议

- 现有测试覆盖缺口：...
- 优先补充：...
- 预估测试文件数 / 用例数：...

## 输出格式

按此模板输出，嵌入 TEST-REPORT.md 的"测试策略"章节。
