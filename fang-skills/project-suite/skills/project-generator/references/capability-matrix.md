# Capability Matrix — Generator

## 能力边界

### 保证能力

✓ 组件/页面/API 模块代码生成
✓ CRUD 样板代码
✓ 遵循项目现有规范和模式
✓ TypeScript 类型定义
✓ 错误处理 + 加载状态

### 不做

✗ 需求分析（→ planner）
✗ 架构设计（→ architect）
✗ 测试编写（→ tester，但可生成基础测试骨架）
✗ 安全审计
✗ 性能优化（不做超出项目现有水平的优化）

> 触发词命中但意图落在"不做"区域 → 告知用户并推荐正确的 skill。

## 前置条件

| 条件 | 必须 | 缺失时行为 |
|------|------|-----------|
| `.project-knowledge/` | 推荐 | 使用通用模式，代码可能不符合项目规范 |
| `PLAN.md` | 否 | 直接生成 |
| `ARCHITECTURE.md` | 否 | 使用默认模式 |
