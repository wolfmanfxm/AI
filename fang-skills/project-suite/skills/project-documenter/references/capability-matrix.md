# Capability Matrix — Documenter

## 能力边界

### 保证能力

✓ API 文档生成（从代码提取接口定义）
✓ README 编写/更新
✓ 架构决策记录（ADR）
✓ Changelog 生成（从 git log + PR）
✓ 组件文档（Props/Events/Slots 表格）

### 不做

✗ 用户手册 / 面向终端用户的文档
✗ 多语言翻译
✗ 培训材料
✗ 视频/图文教程
✗ 法律文书

> 触发词命中但意图落在"不做"区域 → 告知用户并推荐正确的 skill。

## 文档规则

| 规则 | 原因 |
|------|------|
| 从代码提取，不编造 | 文档准确性优先于完整性 |
| 引用 file:line | 读者可溯源验证 |
| 匹配已有文档风格 | 保持一致性 |
| 中文描述 + 代码原文 | 描述清晰 + 代码准确 |
