# Pipeline Orchestrator — 触发词

## 中文触发词
全流程, 一键执行, 自动编排, pipeline, 完整链路, 端到端, 从分析到发布, 自动化开发, 自动构建, 一键生成, 全自动, 流程编排

## 英文触发词
full pipeline, orchestrate, end-to-end, auto sdlc, run all, complete workflow, auto build, pipeline execution, automated development

## 歧义处理
- "全流程" → 展示 pipeline 选项（full-sdlc / analyze-plan-build / quick-change），而非自动执行
- "一键生成" → 先确认 scope，再选择 pipeline
