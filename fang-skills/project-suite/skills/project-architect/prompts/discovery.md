# Discovery — Architect

## Actions

0. **Context Resolver** → [Context Resolver](../../../runtime/contracts/context-resolver.md)：查询已有 decisions/patterns → 避免重复设计
1. 确认设计范围：技术选型 / 模块设计 / API 契约 / 综合设计
2. 收集约束：技术栈限制、团队能力、时间预算、已有架构、遗留系统
3. CHECKPOINT — 展示设计范围 + 约束清单

## Exit

- 设计范围已确认（选型/模块/API/综合）
- 约束清单已列出

## Failure

| Condition | Action |
|-----------|--------|
| 设计范围完全未指定 | 🔴 BLOCKED — 提示先执行 `/project-planner` |
