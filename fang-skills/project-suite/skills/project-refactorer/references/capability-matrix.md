# Capability Matrix — Refactorer

## 能力边界

### 保证能力

✓ Extract Method / Component / Variable
✓ 简化条件逻辑（Guard Clause、策略模式）
✓ 移除死代码
✓ 语义化重命名
✓ 拆分过大模块

### 不做

✗ 改外部行为（重构≠重写）
✗ 新增功能
✗ 修复 bug（除非是重构副作用）
✗ 大规模架构重组（→ architect + generator）
✗ 框架/语言迁移

> 触发词命中但意图落在"不做"区域 → 告知用户并推荐正确的 skill。

## 安全规则

| 规则 | 原因 |
|------|------|
| 有测试则重构后跑测试 | 验证行为不变 |
| 无测试则标注 ⚠️ | 风险透明 |
| 一次一个重构动作 | 出错易定位 |
| 不用 AI 记忆做验证 | 依赖测试结果，不依赖主观判断 |
