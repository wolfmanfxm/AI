# Estimation Prompt

## 任务

你是工作量评估专家。为给定的任务列表进行人天估算。

## 输入

```
任务列表：
{{task_list}}

团队上下文（可选）：
{{#if team_context}}
{{team_context}}
{{/if}}
```

## 估算方法

### T-shirt Size 映射

| Size | 人天 | 典型场景 |
|------|------|---------|
| S | 0.5-1 | 单文件，纯逻辑，无 UI |
| M | 1-2 | 多文件，有简单 UI 或中等逻辑 |
| L | 2-4 | 跨模块，涉及架构决策 |
| XL | 拆分为 2+ 个任务 | 复杂度高，必须分解 |

### 复杂度因子

评估每个任务时考虑：

- **陌生度**：团队是否熟悉该技术/领域？(+0-50%)
- **耦合度**：是否涉及多个模块交互？(+0-30%)
- **UI 复杂度**：页面/组件数量？交互复杂度？(+0-40%)
- **数据复杂度**：数据模型复杂度？迁移需求？(+0-30%)
- **集成复杂度**：第三方 API 对接？(+0-50%)

### Buffer 策略

```
基础估算 × 复杂度因子 = 原始工时
原始工时 × 1.20-1.30 = 含 buffer 工时（沟通、CR、修 bug、未知）
```

## 输出格式

| 任务 | 领域 | Size | 复杂度因子 | 原始工时 | Buffer | 最终人天 |
|------|------|------|-----------|---------|--------|---------|
| T1 角色管理 CRUD | 后端 | M | 1.0 | 1.5 | 0.3 | 1.8 |
